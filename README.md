### UrbexBench

Een benchmark voor het evalueren van visuele taalmodellen voor de classificatie van verlaten/niet-verlaten satelliet beelden. Dit project test hoe goed verschillende AI-modellen kunnen classificeren of een locatie op satellietbeelden verlaten is of niet.

- **Talen gebruikt:** Python
- **Link:** https://github.com/ruben-blok/urbexbench

### Urbexium

Urbexium is een platform waar mensen verlaten locaties kunnen bekijken, delen en ontdekken. Het maakt gebruik van AI- en machine learning-technologie om gebruikers te helpen deze unieke plekken te vinden.

- **Talen gebruikt:** Python, JavaScript
- **Link:** https://urbexium.com
